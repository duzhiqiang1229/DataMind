# DataMind 企业智能平台详细功能设计说明书

> 版本：v2.0 | 更新日期：2026-08-06  
> 变更说明：更新各模块集成方式为 API 连接模式，细化执行链路和任务状态管理

---

## 1. 文档说明

本文档用于指导 DataMind 企业智能平台产品设计、研发实现、系统集成和项目实施。平台目标是建设统一的数据采集、加工、存储、指标、治理、服务和 AI 分析能力。

**核心架构原则**：6 大组件已独立部署，DataMind 通过 API 连接使用。

## 2. 产品总体架构

```
用户 → DataMind 平台门户 → FastAPI 后端服务 → 外部组件 API
```

核心组件及集成方式：

| 组件 | 职责 | 集成方式 |
|------|------|---------|
| DataX | 数据同步 | Airflow DAG 执行 CLI |
| Spark | 数据加工计算 | Airflow DAG 提交 spark-sql/spark-submit |
| Airflow | 任务编排 | REST API 直连 |
| Doris | 分析型数据仓库 | MySQL 协议直连 |
| Cube | 指标语义层 | REST API 直连 |
| OpenMetadata | 数据治理 | REST API 直连 |

## 3. 数据源管理中心

**功能定位**：统一管理企业数据来源。

主要功能：
1. 数据源注册
2. 连接测试
3. 数据源权限管理
4. 数据源状态监控

支持 Oracle、MySQL、PostgreSQL、文件、接口等数据源。

## 4. 数据集成中心（DataX）

**功能定位**：实现业务系统与数据仓库之间的数据同步，通过 Airflow 统一执行。

主要功能：
1. 同步任务创建（配置源表/目标表/字段映射）
2. 字段映射管理
3. 全量同步
4. 增量同步
5. DataMind 生成 DataX job JSON 存库
6. 通过 Airflow REST API 触发 DAG 执行（预置模板 + 参数触发）
7. 同步状态监控（轮询 Airflow API，约 10 秒间隔）
8. 同步日志查看（通过 Airflow API 获取日志）

典型流程：Oracle → DataMind 配置 → 生成 DataX JSON → Airflow 执行 DataX → Doris ODS

## 5. 数据开发中心（Spark）

**功能定位**：完成数据清洗、转换和加载，支持 SQL 和 PySpark 两种模式。

主要功能：
1. SQL 开发（通过 Doris MySQL 协议直连查询）
2. Spark SQL 任务管理（存库 + Airflow 执行）
3. PySpark 脚本管理（存库 + Airflow 执行）
4. 数据模型管理（ODS/DWD/DWS/ADS 模型目录、表结构设计、字段设计、模型 SQL 开发、模型版本管理、模型发布）
5. 任务版本管理
6. 发布管理（发布版本管理、发布记录查看、发布状态跟踪、发布结果记录）
7. 运行状态监控（轮询 Airflow API）
8. 日志查看

数据链路：ODS → DWD → DWS → ADS。先建分层结构，使用模拟数据验证。

## 6. 调度中心（Airflow）

**功能定位**：管理数据任务执行流程，通过 REST API 集成。

功能：
1. DAG 流程管理（查看预置模板 DAG）
2. 定时调度（通过 Airflow API 配置）
3. 依赖管理
4. 任务触发（REST API 传参触发）
5. 失败重试
6. 运行监控（轮询 Airflow API）
7. 运行日志查看（通过 Airflow API 获取日志）

## 7. 数据仓库中心（Doris）

**功能定位**：企业统一分析型数据仓库，通过 MySQL 协议直连。

功能：
1. 数据库管理
2. 数据表管理
3. 数仓分层管理（ODS/DWD/DWS/ADS）
4. 查询服务（SQL 工作台）
5. 数据分析支持

分层：ODS、DWD、DWS、ADS。先建分层结构，使用模拟数据验证链路。

## 8. 指标中心（Cube）

**功能定位**：建立企业统一指标口径，通过 Cube REST API 集成。

功能：
1. 指标定义
2. 指标审核
3. 指标维度管理
4. Cube 模型管理
5. 指标查询（通过 Cube REST API 实时查询）
6. 指标 API 服务

示例：销售收入 = 订单金额 - 退款金额

## 9. 数据治理中心（OpenMetadata）

**功能定位**：建设企业数据资产治理体系，通过 OpenMetadata REST API 集成。

功能：
1. 数据目录
2. 元数据管理
3. 数据血缘
4. 数据质量
5. 数据责任管理

## 10. 数据服务中心

**功能定位**：向业务系统、BI 和 AI 应用提供统一数据服务。

功能：
1. API 管理
2. 查询服务
3. 权限控制
4. 调用统计

## 11. 企业语义层

**功能定位**：连接业务知识和数据能力。

管理内容：
- 业务对象
- 业务关系
- 业务规则
- 指标解释
- 分析路径

## 12. AI Agent 智能分析

流程：用户问题 → AI Agent → 企业语义层 → Cube → Doris → 分析结果

支持自然语言问数、经营分析和原因分析。

## 13. 用户角色设计

| 角色 | 职责 |
|------|------|
| 管理员 | 系统配置和权限管理 |
| 数据工程师 | 数据开发和任务管理 |
| 分析师 | 指标分析和数据查询 |
| 业务人员 | 查看经营指标 |

## 14. 非功能设计

- **性能**：支持高并发查询和大规模数据处理
- **安全**：支持认证（JWT）、权限（RBAC）、审计
- **部署**：DataMind 自身支持 Docker 和 Kubernetes（外部组件已独立部署）

## 15. MVP 建设路线

### MVP 第一阶段（核心链路）

- 登录 + RBAC 权限体系
- 首页驾驶舱
- 数据源管理 + DataX 同步
- Doris SQL 查询工作台
- 系统管理（用户/角色/权限 + 组件连接配置）

### 第二阶段（扩展）

- Spark 任务管理（SQL + PySpark）
- Airflow 调度管理
- Cube 指标中心
- OpenMetadata 治理入口

### 第三阶段（智能化）

- 企业语义层
- AI Agent
- 智能问数
