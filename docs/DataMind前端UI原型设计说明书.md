# DataMind 前端 UI 原型设计说明书

> 版本：v2.0 | 更新日期：2026-08-06  
> 变更说明：更新前端工程结构，明确从零自建 Vue3+TS+ElementPlus，细化页面组件设计

---

## 1. 文档概述

本文档用于指导 DataMind 企业智能数据中台前端 UI 设计和 Vue 开发实现，定义系统页面结构、布局规范、功能组件、交互方式和用户操作流程。

**设计目标**：提供统一、专业、高效的数据工程工作台体验。

## 2. 前端整体设计原则

1. 统一门户入口
2. 统一视觉规范
3. 面向数据工程师工作流程设计
4. 高频功能自主开发
5. 底层专业工具能力通过 API 集成方式使用

**技术方案**：Vue 3.5 + TypeScript 5 + Element Plus + ECharts + Pinia

**前端方案决策**：从零自建，不使用 Admin 框架模板。

## 3. 全局布局设计

采用企业后台管理系统经典布局：

```
+--------------------------------------------------+
| Logo | DataMind 企业智能平台    | 搜索 | 用户 | 设置 |
+--------------------------------------------------+
|       |                                          |
| 菜单  |           内容工作区                       |
| 导航  |                                          |
|       |                                          |
+--------------------------------------------------+
```

布局组成：
- 顶部导航栏（Logo、系统名称、用户信息、设置入口）
- 左侧功能菜单（可折叠，支持多级）
- 内容区域（路由视图）
- 状态提示区域（组件连接状态指示）

## 4. 首页驾驶舱设计

**页面定位**：展示 DataMind 整体运行状态。

页面组件：

| 序号 | 组件 | 数据来源 |
|------|------|---------|
| 1 | 数据任务运行统计卡片 | Airflow API |
| 2 | 数据同步状态趋势图 | 本地库 task_instances |
| 3 | 数据资产统计 | OpenMetadata API |
| 4 | 指标服务调用统计 | Cube API |
| 5 | 数据质量概览 | OpenMetadata API |
| 6 | 组件连接状态面板 | component_configs |
| 7 | 系统资源监控图表 | 本地库 |

图表组件采用 ECharts。

## 5. 数据源管理页面

**页面目标**：管理企业数据连接。

页面结构：
- 顶部：查询条件（名称、类型、状态）和新增按钮
- 中间：数据源列表（Element Plus Table + 分页）
- 右侧/弹窗：数据源配置表单

表格字段：

| 字段 | 说明 |
|------|------|
| 数据源名称 | - |
| 类型 | Oracle/MySQL/PostgreSQL 等 |
| 地址 | host:port |
| 数据库 | database_name |
| 状态 | active/inactive |
| 创建时间 | - |

操作：新增、编辑、测试连接、删除。

## 6. 数据集成（DataX）页面

**页面目标**：管理数据同步任务，配置后通过 Airflow 执行。

页面组件：
- 同步任务列表（表格 + 状态筛选）
- 创建任务向导（步骤引导）
- 字段映射配置（源表字段 → 目标表字段拖拽映射）
- 执行日志（实时刷新，轮询 Airflow API）

任务配置步骤：

| 步骤 | 内容 |
|------|------|
| 1 | 选择数据源 |
| 2 | 配置目标表（Doris ODS 表） |
| 3 | 字段映射 |
| 4 | 设置同步方式（全量/增量） |
| 5 | 保存任务（生成 DataX job JSON 存库） |
| 6 | 触发执行（调用 Airflow API） |

任务状态展示：pending → running → success / failed（轮询 Airflow API 更新）。

## 7. 数据开发页面

**页面目标**：提供 SQL 和 Spark 开发能力。

页面组件：
- SQL 编辑器（CodeMirror / Monaco Editor）
- 数据预览（结果表格）
- 任务配置面板
- 运行结果展示
- 历史版本管理

支持：
- SQL 开发（通过 Doris MySQL 协议直连查询）
- Spark SQL 任务开发（存库 + Airflow 执行）
- PySpark 脚本开发（存库 + Airflow 执行）
- 数据模型管理（ODS/DWD/DWS/ADS 模型设计）
- 发布管理（模型/任务发布上线）

### SQL 工作台布局

```
+----------+------------------+------------------+
| 库表树    |  SQL 编辑器      |  查询结果         |
| Doris    |                  |                  |
| ├─ ODS   |  SELECT ...     |  | col1 | col2 | |
| ├─ DWD   |  FROM ...       |  |------|------| |
| ├─ DWS   |  WHERE ...      |  | data | data | |
| └─ ADS   |                  |                  |
+----------+------------------+------------------+
```

### 数据模型管理布局

```
+----------+------------------+------------------+
| 模型目录  |  模型字段设计    |  DDL 预览        |
| ODS      |                  |                  |
| ├─ 模型A | | 字段名 | 类型 | | CREATE TABLE... |
| DWD      | | id     | BIG  | | ...              |
| ├─ 模型B | | name   | VAR  | |                  |
| DWS      | | amount | DEC  | |                  |
| ADS      | [+ 添加字段]     | [保存版本] [发布] |
+----------+------------------+------------------+
```

- 模型按 ODS/DWD/DWS/ADS 分层树形展示
- 支持字段设计（名称、类型、注释、主键、分区）
- 自动生成建表 DDL
- 版本管理（保存版本快照、对比差异）
- 发布到 Doris（执行建表）

### 发布管理布局

```
+-------------------+----------------------------------+
| 发布任务列表       |  发布详情                         |
| | 名称 | 类型 | 状态| | 发布对象列表 |          |
| | 发布1| 模型 | 成功| | - dwd_order_detail        |
| | 发布2| 任务 | 执行| | - dws_sales_summary       |
| | 发布3| 模型 | 待发| |                           |
|                   | [执行发布] [查看记录]            |
+-------------------+----------------------------------+
```

- 支持创建发布任务（选择数据模型/Spark任务/DataX任务）
- 发布到目标环境（dev/staging/production）
- 发布状态跟踪（待发布/执行中/成功/失败）
- 发布记录查看

## 8. 调度中心页面

基于 Airflow REST API 能力集成。

页面展示：
- DAG 列表（从 Airflow API 获取）
- 任务状态（pending/running/success/failed）
- 调度时间
- 执行日志（通过 Airflow API 获取日志）
- 运行结果统计

操作：查看、触发、停止、重试（调用 Airflow REST API）。

## 9. 数据仓库页面

**页面目标**：管理 Doris 数据模型，通过 MySQL 协议直连。

功能：
- 数据库浏览（Doris 库列表）
- 表管理（表详情、字段信息）
- 字段查看
- 模型关系查看
- SQL 查询（内嵌 SQL 工作台）

支持 ODS、DWD、DWS、ADS 分层展示。先建分层结构，使用模拟数据验证。

## 10. 数据资产页面

基于 OpenMetadata REST API 能力集成。

页面：
- 数据目录（从 OpenMetadata API 获取）
- 表详情
- 字段说明
- 血缘关系图（ECharts 拓扑图）
- 数据质量信息

重点展示数据资产关系。

## 11. 指标中心页面

**页面目标**：管理企业统一指标，通过 Cube REST API 集成。

页面组件：
- 指标列表
- 指标详情
- 指标计算规则
- 关联 Cube 模型
- 指标查询（调用 Cube API 实时查询）

示例：销售收入 = 订单金额 - 退款金额

## 12. 数据服务页面

**页面目标**：管理数据 API 能力。

功能：
- API 列表
- API 配置
- 参数管理
- 调用记录
- 返回结果测试

## 16. 页面交互规范

操作反馈：

| 场景 | 反馈 |
|------|------|
| 操作成功 | Element Plus Message success |
| 操作失败 | Element Plus Message error |
| 加载中 | Loading 遮罩 |
| 空数据 | 空状态提示组件 |

危险操作：删除、停止任务需要二次确认（Element Plus MessageBox）。

## 17. 前端目录规划

```
frontend/src/
├── api/            # 接口封装
│   ├── request.ts   # Axios 实例 + 拦截器
│   └── index.ts     # API 模块定义
├── assets/
│   └── styles/      # 全局样式 + 变量
├── components/       # 公共组件
├── layouts/
│   └── MainLayout.vue # 主布局
├── router/
│   └── index.ts      # 路由 + 守卫
├── stores/
│   └── auth.ts       # Pinia 认证状态
├── types/            # TypeScript 类型
├── utils/            # 工具类
└── views/            # 页面
    ├── login/         # 登录
    ├── dashboard/     # 首页驾驶舱
    ├── datasource/    # 数据源管理
    ├── datax/         # DataX 任务
    ├── query/         # SQL 工作台
    └── system/user/   # 用户管理
```

## 18. MVP 页面范围

第一阶段开发页面：

| 页面 | 复杂度 | 说明 |
|------|--------|------|
| 登录页 | 低 | 用户名密码 + JWT |
| 全局布局 + 菜单 + 路由 | 中 | 侧边栏 + 顶部导航 |
| 首页驾驶舱 | 中高 | 统计卡片 + 趋势图 + 组件状态 |
| 数据源管理 | 中 | 表格 + 表单 + 连接测试 |
| DataX 任务管理 | 高 | 向导 + 字段映射 + 状态监控 |
| SQL 工作台 | 高 | 库表树 + 编辑器 + 结果表格 |
| 用户管理 | 中 | 表格 + 表单 + 角色分配 |

第二阶段扩展页面：
- Spark 任务管理
- Airflow 调度入口
- Cube 指标中心
- OpenMetadata 入口
