# DataMind 产品信息架构设计文档

> 版本：v2.0 | 更新日期：2026-08-06  
> 变更说明：更新组件集成方式为 API 连接模式，调整 MVP 范围，明确 Integration Layer 结构

---

## 1. 文档概述

本文档定义 DataMind 企业智能数据中台的产品信息架构，包括系统菜单结构、功能模块划分、页面规划、用户操作路径以及前端建设指导。

**DataMind 定位**：数据工程师工作台 + 企业智能数据平台。

**架构原则**：DataMind 不部署底层组件，通过 API 连接已部署的 DataX、Spark、Airflow、Doris、Cube、OpenMetadata。

## 2. 产品整体信息架构

DataMind 采用统一门户设计，通过一个入口管理企业数据能力。

```
用户 → DataMind 门户 → 业务功能模块 → 外部组件 API 服务
```

底层组件（已外部部署）：
- DataX（通过 Airflow 执行）
- Spark（通过 Airflow 执行）
- Airflow（REST API 直连）
- Doris（MySQL 协议直连）
- Cube（REST API 直连）
- OpenMetadata（REST API 直连）

## 4. 首页驾驶舱

**功能定位**：展示 DataMind 整体运行状态，为用户提供平台运行总览。

功能：
- 平台运行状态监控
- 数据任务运行情况
- 数据同步状态
- 数据资产统计
- 指标服务调用情况
- 数据质量概览
- **组件连接状态**（展示 6 大组件 API 连接状态）

## 5. 数据管理中心

**功能定位**：管理企业数据来源和数据采集能力，是数据进入 DataMind 平台的入口。

### 5.1 数据源管理

**功能定位**：统一管理企业业务系统数据连接。

功能：
- 数据源列表
- 新增数据源
- 编辑数据源
- 删除数据源
- 数据源连接测试
- 数据源状态管理

### 5.2 数据集成管理

**功能定位**：基于 DataX 实现企业数据同步，通过 Airflow 统一执行。

功能：
- 同步任务创建（配置源表/目标表/字段映射）
- DataMind 生成 DataX job JSON 并存库
- 字段映射管理
- 全量同步 / 增量同步
- 触发 Airflow DAG 执行（预置模板 + 参数触发）
- 同步状态监控（轮询 Airflow API）
- 同步日志查看（通过 Airflow API 获取日志）

## 6. 数据开发中心

**功能定位**：提供企业数据工程开发能力，支持 SQL 和 PySpark 两种开发模式。

### 6.1 SQL 开发工作台

**功能定位**：提供 SQL 编写、调试和数据查询能力。

功能：
- SQL 编辑器
- SQL 执行（通过 Doris MySQL 协议直连）
- 数据预览
- SQL 历史管理
- 查询结果展示

### 6.2 Spark 任务管理

**功能定位**：管理数据加工计算任务，支持 SQL 和 PySpark 脚本。

功能：
- 创建 Spark 任务（选择 SQL 模式或 PySpark 模式）
- 配置任务参数（资源、变量等）
- SQL 文件 / PySpark 脚本管理（存入 PostgreSQL）
- 任务提交执行（通过 Airflow DAG 触发）
- 运行状态查看（轮询 Airflow API）
- 日志查看

### 6.3 数据模型设计

**功能定位**：负责数据仓库模型设计和开发过程。

功能：
- 模型目录管理
- 表结构设计
- 字段设计
- 模型版本管理

支持 ODS、DWD、DWS、ADS 模型设计。先建分层结构，使用模拟数据验证。


## 7. 调度中心

**功能定位**：统一管理数据任务运行流程，基于 Airflow REST API。

二级菜单：
- 7.1 DAG 管理
- 7.2 运行监控
- 7.3 调度配置

功能：
- DAG 管理（查看 Airflow 中预置的 DAG 模板）
- 定时调度（通过 Airflow API 配置 DAG 调度）
- 任务依赖
- 运行监控（轮询 Airflow API，约 10 秒间隔）
- 失败重试
- 日志查看（通过 Airflow API 获取日志）


## 9. 数据资产中心

**功能定位**：管理企业数据资产，基于 OpenMetadata REST API 集成。

功能：
- 数据目录
- 元数据管理
- 字段信息管理
- 数据血缘
- 数据质量信息
- 数据责任人管理

## 10. 指标中心

**功能定位**：建设企业统一指标体系，基于 Cube REST API 集成。

功能：
- 指标定义
- 指标分类
- 指标维度管理
- 指标计算模型
- 指标查询（通过 Cube REST API）
- 指标 API 服务

## 11. 数据服务中心

**功能定位**：向业务系统、BI 和 AI 应用提供统一数据服务能力。

功能：
- API 创建
- API 配置
- API 测试
- 查询服务
- 调用统计
- 数据访问控制

## 12. 系统管理

**功能定位**：管理 DataMind 基础平台能力。

功能：
- 用户管理
- 角色管理
- 权限管理（RBAC）
- **组件连接配置管理**（管理 6 大外部组件的地址、端口、认证信息）
- 操作日志
- 系统配置

## 13. AI 智能分析中心

**功能定位**：实现企业智能分析和自然语言问数能力。

流程：用户问题 → AI Agent → 企业语义层 → Cube 指标服务 → Doris 数据查询 → 分析结果

未来扩展：
- 企业语义层
- 知识图谱
- 智能问数

## 14. 模块职责关系

| 模块 | 职责 |
|------|------|
| 数据开发中心 | 数据模型设计、开发和发布 |
| 数据仓库中心 | 已发布模型的存储、查看和运行管理 |
| 数据资产中心 | 数据治理和资产管理 |
| 指标中心 | 业务指标计算和语义服务 |
| AI 智能分析中心 | 业务知识理解和智能分析 |

## 15. MVP 建设范围

MVP 第一阶段建设：
- 首页驾驶舱
- 数据源管理
- DataX 任务管理（配置 + Airflow 执行）
- Doris SQL 查询工作台
- 系统管理（用户/角色/权限 + 组件连接配置）

第二阶段扩展：
- Spark 任务管理（SQL + PySpark）
- Airflow 调度入口
- Cube 指标管理
- OpenMetadata 治理入口
