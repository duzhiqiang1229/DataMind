# DataMind 开发实施计划与项目里程碑

> 版本：v2.0 | 更新日期：2026-08-06  
> 变更说明：基于 1-2 人数据方向团队调整实施计划，更新 MVP 范围为核心链路优先

---

## 1. 项目概述

本文档用于规划 DataMind 企业智能数据中台的研发实施过程，包括项目阶段划分、功能范围、人员分工、开发计划、里程碑节点和上线规划。

**DataMind 定位**：数据工程师工作台 + 企业智能数据平台。

**建设目标**：通过 API 连接已部署的 DataX、Spark、Airflow、Doris、Cube、OpenMetadata，构建统一的数据集成、数据开发、数据仓库、指标服务、数据治理和智能分析平台。

## 2. 项目建设原则

1. **MVP 优先**：先建设核心数据能力，再逐步扩展智能能力
2. **组件复用**：充分利用已部署的开源组件 API 能力，减少重复开发
3. **平台化建设**：统一门户、统一权限、统一服务入口
4. **模块化开发**：各功能独立演进
5. **持续迭代**：通过版本迭代完善平台能力
6. **务实交付**：1-2 人团队聚焦核心链路，不追求全量功能

## 3. 项目总体阶段规划

项目分为五个阶段：

| 阶段 | 内容 | 目标 |
|------|------|------|
| 第一阶段 | 基础平台建设 | 门户 + 权限 + 框架 |
| 第二阶段 | 数据集成与开发能力建设 | DataX + Spark + Airflow |
| 第三阶段 | 指标和数据服务建设 | Cube + 数据 API |
| 第四阶段 | 数据治理建设 | OpenMetadata |
| 第五阶段 | 智能分析能力建设 | AI Agent |

## 4. 第一阶段：基础平台建设

**目标**：完成 DataMind 基础框架搭建。

建设内容：
1. 前端门户框架（Vue3 + TS + Element Plus）
2. FastAPI 后端基础框架
3. 用户权限体系（RBAC + JWT）
4. 数据库初始化（PostgreSQL 16 张表）
5. Integration Layer 基础结构
6. 组件连接配置管理（component_configs 表 + UI）
7. Docker 开发环境

交付成果：DataMind 基础平台可运行，可连接外部组件 API。

## 5. 第二阶段：数据集成与开发能力建设

**目标**：实现企业数据进入平台并完成加工。

建设内容：
1. 数据源管理（CRUD + 连接测试）
2. DataX 任务管理（配置生成 + Airflow 执行）
3. Spark 任务管理（SQL + PySpark + Airflow 执行）
4. Airflow 调度集成（DAG 模板 + 状态轮询）
5. 数据模型管理（ODS/DWD/DWS/ADS 模型设计、字段管理、版本管理）
6. 发布管理（模型/任务发布上线、发布记录）
7. Doris SQL 查询工作台

业务流程：业务系统 → DataMind 配置 → Airflow 执行 DataX → Doris ODS → Airflow 执行 Spark 加工 → DWD/DWS/ADS

## 6. 第三阶段：指标服务与数据应用建设

**目标**：建立统一指标服务能力。

建设内容：
1. Cube 集成（REST API 适配器）
2. 指标定义管理
3. 指标模型管理
4. 指标查询接口
5. 数据服务 API

实现：业务人员通过统一指标获取分析结果。

## 7. 第四阶段：数据治理建设

**目标**：建设企业数据资产管理体系。

建设内容：
1. OpenMetadata 集成（REST API 适配器）
2. 数据目录
3. 元数据管理
4. 数据血缘展示
5. 数据质量信息管理

形成企业数据资产视图。

## 8. 第五阶段：AI 智能分析建设

**目标**：实现智能问数和经营分析。

建设内容：
1. 企业语义层
2. AI Agent
3. 自然语言查询
4. 自动生成分析结果

流程：用户问题 → AI Agent → 企业语义层 → Cube → Doris → 分析结果

## 9. MVP 版本范围

### MVP 第一阶段重点建设

**前端页面**：
- 登录页
- 全局布局 + 菜单 + 路由
- 首页驾驶舱（统计卡片 + 趋势图 + 组件状态）
- 数据源管理（表格 + 表单 + 连接测试）
- DataX 任务管理（向导 + 字段映射 + 状态监控）
- SQL 工作台（库表树 + 编辑器 + 结果表格）
- 用户管理

**后端服务**：
- 用户权限服务（RBAC + JWT）
- 数据源服务
- DataX 服务（job JSON 生成 + Airflow 触发）
- Doris 查询服务（MySQL 协议）
- 组件连接配置管理
- Airflow 状态轮询调度器

**基础组件**（已部署）：
- Doris（已部署，DataMind 连接）
- Airflow（已部署，DataMind 连接）
- PostgreSQL + Redis（DataMind 自部署）

### 预估时间线（1-2 人数据方向团队）

| 里程碑 | 预估时间 | 产出 |
|--------|---------|------|
| 环境搭建 + 后端脚手架 | 2-3 周 | FastAPI + JWT + RBAC 可用 |
| 前端框架 | 1-2 周 | 登录/菜单/布局可用 |
| 数据源 + DataX | 3-4 周 | 数据同步链路打通 |
| Doris 查询 + 首页 | 2-3 周 | SQL 工作台 + 看板 |
| **MVP v1 可用** | **约 3-4 个月** | **基础数据平台** |

后续 Cube 指标、OpenMetadata 治理、AI 分析各需 1-2 个月追加。
